# Interactive Portfolio

A modern, responsive, and interactive developer portfolio designed to showcase projects, skills, experience, and contact information with engaging UI/UX and smooth animations.

---

## Features

- **Interactive UI/UX:** Engaging animations, micro-interactions, and 3D/canvas effects.
- **Projects Showcase:** Detailed cards with live demo links, repository source code, and tech tags.
- **Skills & Tech Stack:** Visual breakdown of languages, frameworks, libraries, and tools.
- **Experience & Education:** Timeline view of work experience and background.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Contact Form:** Integrated messaging / mailto support for easy outreach.
- **Dark / Light Mode:** Theme toggle with persistent user preference.

---

##  Tech Stack

- **Frontend:** React / Next.js / HTML5, CSS3, JavaScript (TypeScript)
- **Styling:** Tailwind CSS / Styled Components / CSS Modules
- **Animations / 3D:** Framer Motion / Three.js / Lucide Icons
- **Deployment:** Vercel / Netlify / GitHub Pages
